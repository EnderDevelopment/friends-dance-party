# Friends' Dance Party

Friends' Dance Party is a Minecraft plugin that adds custom items and entities to enhance your gameplay. It includes a custom potion/drink item called "Friends' Wine", a custom placeable block or entity named "Friends Doll", and an item called "Friends Remote" to control the doll's behavior. The plugin is designed for Minecraft Bedrock Edition using the modern Script API.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Start or restart your Minecraft server.

## Use

1. **Friends' Wine**:
   - Use the command `/friendswine` to give yourself a Friends' Wine.
   - Drinking the wine will apply a custom effect that triggers a bouncing or spinning animation on the player for 169 seconds.
   - Drinking milk will cancel the effect immediately.

2. **Friends Doll**:
   - Use the command `/friendsdoll` to place a Friends Doll.
   - When placed, the doll will loop a custom audio track in a 20-block radius.
   - All entities/mobs and players within a 50-block radius will have their AI behavior overridden, causing them to stop fighting and attack each other.
   - Affected mobs will execute a hopping/bouncing animation loop synced to the music.

3. **Friends Remote**:
   - Use the command `/friendsremote` to toggle the nearby Friends Dolls between three states:
     - Bounce and spin
     - Bounce only
     - Stop dancing entirely and resume normal AI behavior
